# Тест по лору Кирюшки

Публичный фронтенд квиза. Исходный приватный репозиторий с правильными ответами намеренно не копируется сюда.

## Перед подключением Netlify

1. В Supabase SQL Editor запустить `supabase-public-migration.sql`.
2. Проверить, что публичный RPC `get_public_questions` не возвращает `correct` или `note`, а прямой гостевой запрос к `quiz_content` запрещен.
3. Перенести фотографии под нейтральными именами вида `bags_0.jpg`, `fridge_2.jpg` (имена соответствуют позициям в исходном списке `images`, начиная с нуля). Не загружать файлы с названием `real`.
4. Проверить вход администратора и сохранение изменений.
5. Подключить этот репозиторий к существующему сайту Netlify, ветка `main`, публикация из корня.

## Важное
- В репозитории нет правильных ответов и приватных ключей.
- `config.js` содержит только публичный publishable key.
- Оценка выполняется в Supabase RPC; одноразовый token препятствует простому повтору отправки, но не является полной античит-защитой.
- Три вопроса пока без установленного правильного ответа, вопрос с полкой имеет только одно фото.
