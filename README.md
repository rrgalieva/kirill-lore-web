# Тест по лору Кирюшки

Публичный репозиторий квиза. Основная страница: `index.html`, подключение Supabase: `config.js`, вопросы: `questions.json`.

**Важно:** правильные ответы открыто присутствуют в `index.html` и `questions.json` по выбору владельца. Любой посетитель может посмотреть их через исходный код сайта или GitHub. Отправку баллов в текущей реализации также можно подделать. Для соревновательного квиза потребуется серверная проверка.

## Публикация

Netlify: подключить этот репозиторий, ветка `main`, publish directory `.`, build command пустой.

## Фото

В `index.html` используются изображения в корне сайта под именами вида `bags_real.jpg`, `fridge_a.jpg`. После загрузки соответствующих файлов они появятся в тесте. Незаполненные ответы: bella, drink, saga, shelf.
